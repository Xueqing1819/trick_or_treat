# 捣蛋小龙 · 不给糖就捣蛋

万圣节主题的单文件前端小游戏。扮演一只圆润的黄色小恐龙，挨家挨户敲门要糖：先听住户示范专属敲门暗号，再亲手复敲出来，敲得越准糖越多。

## 玩法

- **敲门暗号**：四户住户（南瓜龙 / 幽灵龙 / 吸血鬼龙 / 木乃伊龙）各有专属暗号，如"两短一长""一长两短"。轻点按钮是短敲，按住约三分之一秒是长敲。全部敲对效果最好，错两下以上算敲错、捣蛋值上涨

- **住户心情值**：每位住户每轮随机偏好"被捣蛋"或"看表演"，选对互动大幅涨心情，心情拉满会大把撒糖

- **双轨计分**：糖果数与捣蛋值并行；捣蛋值爆表触发全街大乱，之后的敲门可能撞上神秘大奖，也可能被赶走

- **图鉴收集**：记录各户累计糖果与撒糖 / 大奖 / 被赶徽章，localStorage 持久化，刷新不丢

- **结算与分享**：每轮 4 次敲门机会，结算给出评级与随机台词，可一键生成战报分享卡片（canvas 绘制，支持长按保存 / 下载）

## 运行方式

零依赖、零构建：下载 `index.html`，浏览器直接打开即玩。也可用任意静态服务器托管（GitHub Pages 开箱即用）。

## 技术特点

- 单 HTML 文件内联全部 CSS / JS，不依赖任何包、构建工具或外部图片

- 角色与场景为纯 SVG 手绘（角色工厂函数按类型生成装扮图层）

- 敲门音效用 Web Audio oscillator 纯代码合成，无音频资源

- 动画只使用 `transform` / `opacity`，并适配 `prefers-reduced-motion`

- Pointer Events 处理按住时长输入，兼容手机触屏与鼠标

- 数据与逻辑分离：可调参数与文案集中在 `CONFIG`，运行时状态集中在 `state`
